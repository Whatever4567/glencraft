# World overhaul (user t559u). Feel: OG Glencraft plus a modern atmospheric look. "I wanna explore this."
1. Terrain: one fully connected grassy mainland like the Scottish Highlands: open lochs, mountain rivers flowing down valleys, rolling hills, mountains. Fewer random holes in the ground.
2. Spawn area: OG Glencraft style, plain oak trees and grass, with haggis spawning there. No dinosaurs at spawn. Elsewhere at most 1 dinosaur at a time.
3. Map edge: round the corners strongly, and put a big ice wall all around instead of the empty void.
4. Volcano: move it away from spawn so it isn't in view at spawn or after a reset (the mountain blocking the way after a reset is a bug). Give spawn more OG foliage. Eruption: much better Pompeii-style effects (lava bombs, ash cloud, pyroclastic flow, glowing debris, smoke columns, camera shake), still lag-free on a phone.
5. Desert music bug: it plays on any sand block. Gate it to the desert/pyramid biome map only, not the block type.
6. Caves: more cave entrances at the foot of mountains that feel like a discovery. Randomise the cave networks per world seed (worm caves, chambers, varied). Each new world gets random terrain from its seed.
7. Paths: winding, curved, natural (spline or noise-meandered), not straight. Where a path meets a cave or hill, cut through it as a tunnel or trench, never bridge over it.
8. UFO: spawns only over the pyramid/desert terrain at night.
9. Foliage: keep the same textures but make them look 3D (crossed quads plus a slight thickness or extra planes, alpha-test cutout with no black fringe: premultiplied alpha, alphaTest about 0.5, and fix the mipmap edge bleeding).
10. "Upload world" in the Test World pause menu: export the current world (blocks, structures, seed) as a compact file. Every new world for every player then starts from that published map. Implement it as: the pause button exports the world as `world_default.json(.gz)`, downloads it, and shows "Send this file to Grok Bot to publish". New World loads `assets/world_default.*` if present; otherwise random generation. Add a "Random world" toggle on New World. (A static GitHub Pages site can't accept uploads from the game itself; publishing goes through the bot committing the file.)
11. Patch notes. Keep performance on Android: generation can sit behind the loading screen.
12. (t560u) The user gives up on the old Test World save: make Test World load by creating a fresh new world in its slot if its save is missing or broken (no Rebuild prompt). Every NEW world starts with the Bag of Everything in the inventory, along with the existing starter kit (map, diamond axe, unlimited XP potion).
13. (t561u) The "Upload world" pause option appears ONLY in a world named exactly "Test World" (case-sensitive). It exports that world as the default map file for new worlds.
