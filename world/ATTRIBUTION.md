# Clydebank map data

`clydebank.bin.gz` is a block-grid bake (1168 x 1168 cells, 4 m per block) of:

- **OpenStreetMap** data, © OpenStreetMap contributors, available under the Open Database License (ODbL) 1.0 — https://www.openstreetmap.org/copyright.
  Extract: Geofabrik `scotland-latest.osm.pbf` (October 2026), bbox 55.894..55.9355 N, -4.4575..-4.3826 E.
  This derived database is likewise offered under the ODbL.
- **Elevation**: AWS Open Data Terrain Tiles (Mapzen terrarium, z15), built from SRTM, EU-DEM (Copernicus), OS Terrain 50 and other open sources.

No Google data is used.
